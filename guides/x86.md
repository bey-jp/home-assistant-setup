# ミニ PC・中古 PC に Home Assistant OS を入れる（AI 向け）

[AI_INSTRUCTIONS.md](../AI_INSTRUCTIONS.md) から来た AI 向けの手順です。
対象：Intel / AMD の 64 ビット PC（N100・N150・N97・Core i など）。Beelink、GMKtec、MINISFORUM などの新品ミニ PC、Lenovo ThinkCentre Tiny・HP EliteDesk Mini・Dell OptiPlex Micro などの中古ビジネス PC。

> **ベータ版**：`scripts/write-haos-x86.sh` は実機での通しテスト前です。ユーザーにそのことを伝え、消えて困るデータのない PC で行ってください。

## 全体の流れ

1. ユーザーのパソコンで、Ubuntu の「お試し用 USB メモリ」を作る（あなたが準備し、書き込みソフトの操作だけユーザー）
2. ミニ PC の BIOS を設定する（ユーザーが操作、あなたが案内）
3. ミニ PC を USB メモリから起動し、スクリプト `scripts/write-haos-x86.sh` で内蔵ディスクに HA OS を書き込む（ユーザーがコマンドを1行貼るだけ）
4. USB メモリを抜いて再起動 → HA の画面へ

**ミニ PC の Windows は消えます。** 最初にユーザーに伝え、残したいデータがないか確認します。Windows のライセンスは戻せないことも伝えます（後で Windows に戻したい場合は、メーカーの回復ドライブを先に作ってもらう）。

## 用意するもの

- **USB メモリ 8GB 以上**（中身は消えます）
- ミニ PC を一時的につなぐ**モニター（HDMI）とキーボード**（マウスもあると楽）
- **LAN ケーブル**（ミニ PC とルーターをつなぐ）

## 1. Ubuntu の USB メモリを作る（ユーザーのパソコンで）

1. Ubuntu の最新の LTS 版（デスクトップ、amd64）の ISO を調べます。`https://releases.ubuntu.com/` の一覧から最新の LTS（偶数年の `.04`、例 `26.04`）のフォルダを開き、`ubuntu-<版>-desktop-amd64.iso` と `SHA256SUMS` を確認します。
2. 作業フォルダ（例 `~/ha-setup`、Windows は `%USERPROFILE%\ha-setup`）に ISO をダウンロードし、SHA-256 を `SHA256SUMS` と照合します（Windows は `Get-FileHash`、Mac は `shasum -a 256`）。一致しなければやり直します。約 6GB あるので時間がかかることを伝えます。
3. 書き込みソフト **balenaEtcher** を入れます。
   - Windows：`winget install --id Balena.Etcher -e`
   - Mac：`brew install --cask balenaetcher`（Homebrew がなければ https://etcher.balena.io/ から）
   - Windows で Etcher がうまく動かなければ **Rufus**（`winget install --id Rufus.Rufus -e`）でも構いません。
4. ユーザーに USB メモリを挿してもらい、Etcher を開いて次を押してもらいます。
   - 「Flash from file」→ ダウンロードした ISO を選ぶ（**「Flash from URL」は使わない**）
   - 「Select target」→ USB メモリを選ぶ。**容量を見て、USB メモリであることをユーザーと確認**（止まって確認する場所 1）
   - 「Flash!」→ 終わるまで待つ
   - Windows で「フォーマットしますか」と出たら「キャンセル」を押してもらいます。

## 2. ミニ PC の BIOS を設定する

ユーザーに、ミニ PC にモニター・キーボード・LAN ケーブル・USB メモリをつないでもらい、電源を入れた直後に BIOS のキーを連打してもらいます。

| メーカー | BIOS 設定 | 起動メニュー |
|---|---|---|
| Beelink・GMKtec・MINISFORUM など（AMI BIOS） | Del | F7（機種により F11・F12） |
| Lenovo ThinkCentre | F1 | F12 |
| HP EliteDesk | F10 | F9 |
| Dell OptiPlex | F2 | F12 |

設定する項目（名前は機種で違うので、ユーザーに画面の文字を読んでもらいながら探します）：

1. **Secure Boot（セキュアブート）を無効**にする（HA OS は Secure Boot に対応していません）。
2. **UEFI ブート**を使う。「CSM」「Legacy」は無効にする。
3. （おすすめ）**停電から復帰したら自動で電源を入れる**：「Restore on AC Power Loss」「After Power Loss」「AC Recovery」「State After G3」などを「Power On」「S0」「On」にする。
4. 保存して終了（多くは F10）。

## 3. USB メモリから起動して、HA OS を書き込む

1. 起動メニューのキーを連打して、USB メモリ（「UEFI: 」が付いた項目）を選んでもらいます。
2. Ubuntu の画面が出たら、「Try Ubuntu（Ubuntu を試す）」を選んでもらいます。**「Install Ubuntu」は選ばない。** 言語やキーボードを聞かれたら、そのまま進めて構いません。
3. 右上にネットワーク（有線）がつながっていることを確認してもらいます。
4. 次の1行を Ubuntu の**ターミナル**で実行してもらいます。
   - ターミナルの開き方：キーボードの `Ctrl` + `Alt` + `T`、または左下のアプリ一覧から「Terminal」
   - **入力が難しい場合**：Ubuntu の Firefox でこのページ（`github.com/bey-jp/home-assistant-setup`）を開き、コマンドをコピーして、ターミナルに `Ctrl` + `Shift` + `V` で貼ってもらいます。キーボードの配列が英語になっていて、記号がキーの刻印どおりに打てないことがあるためです。

   ```
   wget -O w.sh https://raw.githubusercontent.com/bey-jp/home-assistant-setup/main/scripts/write-haos-x86.sh && sudo bash w.sh
   ```

5. スクリプトは次のことをします。表示を読み上げてもらい、あなたが判断します。
   - HA OS の最新の安定版を探す（Raspberry Pi 専用のリリースは飛ばします）
   - 内蔵ディスクの一覧を出す。起動中の USB メモリと USB 接続のディスクは候補から外します
   - **書き込むディスク名を聞く**：ユーザーに一覧を読んでもらい、容量と型番から内蔵 SSD（`nvme0n1`、`sda`、eMMC の `mmcblk0` など）を一緒に決めます。ディスクが2台ある機種では特に注意します。
   - **「YES」と入力するまで何も消さない**：ここが「止まって確認する場所 1」です。ユーザーの「はい」を得てから YES と打ってもらいます。
   - ダウンロード → SHA-256 照合 → 書き込み → UEFI の起動項目「HAOS」を登録
6. 「完了しました」と出たら、Ubuntu を電源オフにし（右上のメニュー）、**USB メモリを抜いて**から電源を入れてもらいます。

スクリプトが「中止」と出た場合は、表示されたメッセージに従います。終了コード：1 キャンセル、2 起動方法・環境の問題（UEFI でない等）、3 ネットワーク・ダウンロード、4 ディスクの問題。

### スクリプトを使えない場合（手作業）

Ubuntu の「ディスク（Disks）」アプリでも書き込めます（HA 公式の方法）。

1. Ubuntu の Firefox で https://github.com/home-assistant/operating-system/releases を開き、最新の安定版で `haos_generic-x86-64-<版>.img.xz` があるものをダウンロードしてもらいます（ない版は Raspberry Pi 専用なので、一つ前の版を見る）。
2. 「ディスク」アプリを開き、内蔵ディスクを選ぶ → 右上の「⋮」→「ディスクイメージから復元」→ ダウンロードしたファイル → 「復元を開始」。

### 別の方法：SSD を取り出して書き込む

ミニ PC から M.2 SSD を取り出せて、USB 接続の SSD ケースかアダプタがある場合は、ユーザーのパソコンで Etcher を使って `haos_generic-x86-64-<版>.img.xz` を直接 SSD に書き込み、ミニ PC に戻す方法もあります。ネジを外す作業が必要なので、初心者には上の方法を勧めます。

## 4. 起動と確認

1. LAN ケーブルをつないだまま電源を入れると、モニターに HA OS の起動画面が出て、しばらくすると `homeassistant login:` と HA の URL が表示されます。表示された IP アドレスを教えてもらいます。
2. Windows や Ubuntu が起動してしまう場合は、BIOS の起動順位（Boot Priority）で「HAOS」か内蔵ディスクを一番上にします。
3. 「No bootable device」と出る場合は、Secure Boot が無効になっているか、UEFI モードかを確認します。それでもだめなら、もう一度 Ubuntu で起動し、次で起動項目を登録します（ディスク名は書き込んだもの）。
   ```
   sudo efibootmgr --create --disk /dev/nvme0n1 --part 1 --label "HAOS" --loader '\EFI\BOOT\bootx64.efi'
   ```
4. 5〜20 分待ってから、[AI_INSTRUCTIONS.md](../AI_INSTRUCTIONS.md) の「HA の画面を探す」に従い、`http://homeassistant.local:8123` を開きます。
5. モニターとキーボードは外して構いません。
6. [first-steps.md](first-steps.md) へ進みます。
